# IPTV для Lampa v3.1

Полноценный IPTV-клиент с двухпанельным интерфейсом.

## Интерфейс

```
┌────────────────┬────────────────────────────────┐
│    Группы      │  ★ Избранное / Группа          │
│                │  48 каналов · список / плитки  │
│ ★ Избранное 12 │                                │
│ Все каналы 480 │  1  Первый канал               │
│ Спорт       40 │     12:00–13:00 Новости        │
│ Кино        65 │  2  Второй канал               │
│ Детские     28 │     12:15–14:00 Фильм          │
│ ...            │  ...                           │
└────────────────┴────────────────────────────────┘
   группы слева              каналы справа
```

- **Влево / Вправо** — между группами и каналами  
- **Вверх / Вниз** — навигация  
- **OK** — смотреть / выбрать группу  
- **Долгое нажатие** на канал — избранное  

## В плеере

| Действие | Как |
|----------|-----|
| Предыдущий канал | ← стрелка влево |
| Следующий канал | → стрелка вправо |
| Пауза / Play | Пробел или Media Play/Pause |
| Список каналов | Кнопка **0** на пульте |
| Кнопки на панели | ⏮ ⏯ ⏭ ☰ (если отображаются) |

## Режимы отображения каналов

**Настройки → IPTV → Плитки с логотипами**

- **Выкл** — обычный список (с номером и программой)
- **Вкл** — плитки с логотипами каналов

## Быстрый старт

1. **Настройки → IPTV → Плейлисты → Добавить** — ссылка на M3U  
2. (Опционально) EPG:
   ```
   http://epg.it999.ru/epg2.xml.gz
   ```
3. Откройте **IPTV** в главном меню  

## Настройки

| Параметр | Описание |
|----------|----------|
| **Открывать при входе** | Избранное / Все / Последняя группа |
| **Плитки с логотипами** | Список или плитки |
| **Плейлисты** | Добавить / переключить / удалить |
| **Программа передач** | Ссылка на XMLTV |
| **Сортировать по алфавиту** | Или порядок из плейлиста |
| **Автоповтор при обрыве** | До 3 попыток |
| **CORS-прокси** | Если не грузится плейлист |
